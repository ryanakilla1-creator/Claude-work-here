# Universal PvP Hub — Local Training UI

Interface local de treino para uso em uma experiência sua no **Roblox Studio**.

## Instalação
1. Abra sua experiência no Roblox Studio.
2. No Explorer, abra **StarterPlayer > StarterPlayerScripts**.
3. Crie um **LocalScript**.
4. Copie o conteúdo de [UniversalPvPHub.client.lua](./UniversalPvPHub.client.lua) para esse LocalScript.
5. Execute a experiência.

## Controles
- **RightShift**: mostrar/ocultar o painel.
- **PVP**: botão flutuante para mostrar/ocultar o painel.
- **×**: fechar o painel.
- Abas: Combat, Movement, SHARP, Visual e Settings.

## O que faz
- Interface arrastável.
- Crosshair visual local.
- Anel visual de referência para treino.
- Contador de FPS.
- Indicadores locais e opções visuais.

Este script não implementa aimbot, silent aim, ESP através de paredes, invisibilidade ou manipulação de outros jogadores. Os elementos são apenas visuais e locais.
